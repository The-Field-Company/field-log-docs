# FieldLog Docs

Docusaurus site at `docs.thefieldco.com`. Two locales (en, es) and versioned
docs. Use `bun`, never npm.

## Adding a doc

1. Write `versioned_docs/version-0.0.1/<slug>.mdx`:

   ```mdx
   ---
   sidebar_position: 1
   ---

   # Title

   Content.
   ```

   The `# Title` heading is the sidebar label and page title. The sidebar is
   autogenerated and ordered by `sidebar_position`.

2. Write the Spanish version to the same path under i18n:
   `i18n/es/docusaurus-plugin-content-docs/version-0.0.1/<slug>.mdx`.

3. Mirror both files into the staging copy (`docs/<slug>.mdx` and
   `i18n/es/.../current/<slug>.mdx`) so the next release starts from the same
   content.

4. Screenshots go in `static/img/<slug>.png`, referenced as
   `![alt](/img/<slug>.png)`. Docusaurus optimizes and localizes them.

Every doc must exist in both locales with matching filenames.

## Languages

- Locales: `en` (default, no URL prefix) and `es` (served at `/es/`).
- Only the doc body is per-locale. Internal links and `/img/...` images are
  auto-localized at build time — never hardcode `/es/` prefixes.
- UI chrome (navbar, footer, homepage) uses `translate()` and
  `i18n/es/code.json`. Edit those for chrome strings, not the docs.

## Versioning

- Published docs are the frozen **alpha** release:
  `versioned_docs/version-0.0.1/` and
  `i18n/es/docusaurus-plugin-content-docs/version-0.0.1/`, served at `/docs/`
  and `/es/docs/`.
- `docs/` and `i18n/es/.../current/` are a staging mirror that is **not built**
  (`includeCurrentVersion: false` in `docusaurus.config.ts`). `/docs/next/` does
  not exist, and the version control shows only `v0.0.1 (alpha)`.
- To publish a new version later: set `includeCurrentVersion: true`, make `docs/`
  the source of truth, run

  ```bash
  bun run docs:version 0.0.2
  ```

  then set `includeCurrentVersion` back to `false` and add a matching `versions`
  entry in `docusaurus.config.ts` (add the entry only after the version exists in
  `versions.json`, otherwise `docs:version` fails).

## Preview & verify

```bash
bun start              # dev, English only (single locale)
bun start --locale es  # dev, Spanish only
bun run preview        # build + serve all locales (working language dropdown)
bun run typecheck      # TS check
bun run build          # prod build (broken links/images are fatal)
```

`bun start` serves one locale at a time; the locale dropdown only works under
`bun run preview`. Use `preview` to verify i18n and versioning.
