# FieldLog Docs

Docusaurus site at `docs.thefieldco.com`. Two locales (en, es) and versioned
docs. Use `bun`, never npm.

## Adding a doc

1. Write `docs/<slug>.mdx`:

   ```mdx
   ---
   sidebar_position: 1
   ---

   # Title

   Content.
   ```

   The `# Title` heading is the sidebar label and page title. The sidebar is
   autogenerated and ordered by `sidebar_position`.

2. Write the Spanish version to the same path under i18n:
   `i18n/es/docusaurus-plugin-content-docs/current/<slug>.mdx`.

3. Screenshots go in `static/img/<slug>.png`, referenced as
   `![alt](/img/<slug>.png)`. Docusaurus optimizes and localizes them.

Every doc must exist in both `docs/` and `i18n/es/.../current/` with matching
filenames.

## Languages

- Locales: `en` (default, no URL prefix) and `es` (served at `/es/`).
- Only the doc body is per-locale. Internal links and `/img/...` images are
  auto-localized at build time — never hardcode `/es/` prefixes.
- UI chrome (navbar, footer, homepage) uses `translate()` and
  `i18n/es/code.json`. Edit those for chrome strings, not the docs.

## Versioning

- `docs/` is the unreleased "Next" version, served at `/docs/next/`.
- `versioned_docs/version-<v>/` are frozen releases: latest is `/docs/`,
  older ones are `/docs/<v>/`. `versions.json` lists them.
- New docs land in "Next" only. To release, cut a version:

  ```bash
  bun run docs:version 0.0.2
  ```

  This snapshots `docs/` into `versioned_docs/version-0.0.2/` and promotes it
  to latest. Add a `versions` entry in `docusaurus.config.ts` only after the
  version exists in `versions.json` (doing it first makes `docs:version` fail).

## Preview & verify

```bash
bun start              # dev, English only (single locale)
bun start --locale es  # dev, Spanish only
bun run preview        # build + serve all locales (working language dropdown)
bun run typecheck      # TS check
bun run build          # prod build (broken links/images are fatal)
```

`bun start` serves one locale at a time; the locale dropdown only works under
`bun run preview`. Use `preview` to verify i18n and versioning.
