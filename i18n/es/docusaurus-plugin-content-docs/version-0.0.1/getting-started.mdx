# Primeros pasos

Bienvenido a la documentación de FieldLog.

Estas guías te explican cómo configurar tu primera sesión, recopilar
observaciones en el campo y exportar tus datos cuando termines el trabajo.

## Crear una sesión

Crea tu formulario, arrastra los campos al lienzo y publícalo.

## Desplegar en el campo

Comparte un enlace o un código QR para que tu equipo abra el formulario en
cualquier teléfono.

## Recopilar datos

Las respuestas llegan con GPS, fotos y marcas de tiempo.
